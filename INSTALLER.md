# Контракт будущего установщика

Это описание границ компонентов; готовый EXE/установщик пока не собирается.
`components.json` фиксирует ASR-репозиторий и ревизию, а также опциональную SLM.

## Основной компонент

Qt-приложение, минимальный Python/native runtime, CTranslate2, PyAV, VAD и русская
Whisper. Работает без Ollama и SLM. Инсталлятор должен установить полную модель
в `models/whisper-russian` рядом с EXE либо в пользовательскую директорию данных.
Не упаковывать веса внутрь временного каталога one-file EXE и не копировать всю `.venv`.
Дистрибутив может распространяться одним EXE-установщиком, устанавливающим несколько файлов.

Пути определяет `app_paths.py`: у установленного приложения записи и логи находятся
в `%LOCALAPPDATA%/LocalTranscriber`; `TRANSCRIBER_DATA_DIR` переопределяет это место.
Каталог установленного EXE используется для чтения общих весов, но не для записи логов.
В режиме разработки сохраняется текущая структура проекта.

Размер базовой установки до 5 ГБ — целевой бюджет, пока не подтверждён сборкой.
Русская FP16-модель сама занимает примерно 3,09 ГБ. Существующая `.venv` больше оставшегося
бюджета: потребуется отдельная минимальная сборка и проверка native DLL на чистой Windows.
Не менять рабочие GPU-пакеты ради размера без проверки реального CPU/GPU inference.

## Необязательное форматирование

Пункт в установщике: «Установить локальное ИИ-форматирование (Ollama + Qwen3 4B)».
По умолчанию выключен. Показывать размер runtime и модели отдельно от базового компонента.
Модель Qwen3 4B Instruct занимает около 2,5 ГБ; точные размеры получать из манифестов скачивания.
Скачать и проверить оба компонента до отметки успешной установки. Существующий Ollama
использовать без автоматического обновления и без удаления чужих моделей.
При удалении программы не удалять общий Ollama и его пользовательские модели автоматически.
Установку этого компонента и условия лицензий реализовать на этапе packaging.

`text_formatting.OllamaFormatter` реализует контракт `format(text, instruction,
on_progress=..., cancel=...)` и `close()`. Его можно заменить встроенным локальным
runtime без изменения GUI/core. API допускается только на loopback-адресе.
Приложение не устанавливает пакеты, не скачивает SLM и не обновляет Ollama.
Запуск сервера допускается только после запроса форматирования; открытие окна
и обычная транскрибация не запускают Ollama. Устанавливаемый путь можно передать через
`TRANSCRIBER_OLLAMA_EXECUTABLE`, хранилище весов — `TRANSCRIBER_OLLAMA_MODELS_DIR`.

При переходе к SLM worker выгружает Whisper; SLM запрашивается с `keep_alive=0`.
Запущенный самим приложением сервер закрывается вместе с worker; уже работающий сервер
не завершается. Отмена активного запроса при закрытии окна проверяется даже до первого токена.

## Данные и результат

SLM выключена по умолчанию. Инструкция задаётся перед автоматическим оформлением либо
кнопкой «Оформить…» после распознавания. Исходная транскрипция сохраняется в памяти окна,
доступна кнопкой «Исходный текст» и не заменяется частичным/ошибочным ответом SLM.
Оформленный результат и исходник нужно сохранять через «Сохранить как…», если они нужны после закрытия.
Инструкции ограничены 2000 символами, исходный текст — 24000; превышение лимита
возвращает ошибку, а не молчаливое усечение. Лимиты, контекст, токены ответа и таймаут
вынесены в `config.py`. Автоматическое разбиение длинных текстов пока не реализуется.

## Проверки перед выпуском

Собрать минимальный runtime, проверить CPU/GPU на чистой Windows, измерить размер
загрузки и установки, проверить права обычного пользователя, автономный запуск ASR,
отсутствующий/установленный/общий Ollama, повторную установку и отмену скачивания.
Python/native DLL и Qt-плагины должны разрешаться из установленного runtime;
метаданные GPU-пакетов нужны текущему механизму регистрации DLL-директорий.
