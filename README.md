# Local Transcriber

Локальное Desktop-приложение для транскрибации аудио и видео на русском языке.
Интерфейс — PySide6 (Qt), распознавание — faster-whisper/CTranslate2.
Поддерживаются CPU и NVIDIA GPU; веб-интерфейса и HTTP-сервера нет.

## Запуск

Проверенное окружение: Windows, Python 3.11.9, локальная `.venv`.
Запустите `launch_desktop.bat` или выполните из папки проекта:

```powershell
.\.venv\Scripts\python.exe .\desktop.py
```

Выберите или перетащите файл, укажите CPU/GPU и нажмите «Транскрибировать».
Результат можно скопировать или сохранить в UTF-8.
Тип медиа определяется через PyAV, из видео извлекается аудиодорожка.
Созданные временные файлы удаляются после завершения обработки.

## Зависимости и модели

Точные версии рабочего окружения зафиксированы в `requirements.txt`.
Файл включает PyTorch `2.12.0+cu132`: для нового окружения требуется источник
соответствующих CUDA wheels; установка из одного стандартного PyPI не гарантируется.
Восстановление окружения на другом компьютере пока не проверено.
Не обновляйте GPU/ML-пакеты автоматически: используйте зафиксированные версии.

По умолчанию используется русская дообученная Whisper `large-v3` в формате CTranslate2.
В окне можно вернуться к исходной `large-v3`. В режиме разработки при отсутствии локальных весов модель
загружается при первом распознавании, затем используется локальный кэш. Модель не загружается при открытии окна.
Окружение и веса не входят в Git — на другом компьютере их потребуется подготовить отдельно.
Русские веса ищутся в `models/whisper-russian` (директория данных или установки).
В установленном EXE отсутствующие веса должны быть предоставлены установщиком.

## Необязательное оформление текста

Используется локальная `qwen3:4b-instruct` через Ollama; по умолчанию оформление выключено.
Включите «Оформить после распознавания» и задайте инструкцию в диалоге либо нажмите
«Оформить…» после получения текста. Примеры: «Оформи как конспект» или
«Сплошной текст без сокращений». Исходник доступен кнопкой «Исходный текст».

Нужны установленный Ollama и модель `qwen3:4b-instruct`. Приложение не устанавливает
и не скачивает их автоматически. Если они уже установлены, сервер при необходимости
запускается скрыто только после запроса форматирования. GPU-память Whisper освобождается
перед запуском SLM. При ошибке сохраняется исходная транскрипция.
ИИ-оформление может изменить детали, даже при инструкции сохранять факты.
Проверяйте имена, время, числа и условия по исходнику; это не повторное распознавание аудио.

Архитектура отдельного опционального компонента и лимит основной установки до 5 ГБ
описаны в [INSTALLER.md](INSTALLER.md). Сам установщик пока не реализован.

## Конфигурация

Настройки находятся в `config.py` и переопределяются переменными `TRANSCRIBER_*`.
Например, выбор локальной модели и устройства на текущую сессию PowerShell:

```powershell
$env:TRANSCRIBER_MODEL_SOURCE = 'E:\Models\whisper-ct2'
$env:TRANSCRIBER_DEVICE = 'cuda'
.\.venv\Scripts\python.exe .\desktop.py
```

`MODEL_SOURCE` принимает идентификатор модели или путь к модели в формате CTranslate2.
Доступны также настройки языка, VAD, beam size, batch size и временной директории.

## Структура

- `desktop.py` — окно и точка входа.
- `desktop_worker.py` — операции вне GUI thread.
- `transcription_service.py` — модель и распознавание.
- `preprocessing.py` — определение медиа и подготовка аудио.
- `config.py` — настройки.
- `app_paths.py` — пути установки и пользовательских данных.
- `text_formatting.py` — необязательный локальный адаптер SLM.
- `components.json` — описание компонентов для будущего установщика.
- `test_desktop.py`, `test_transcription_service.py` — быстрые проверки с mock-моделью.
- `benchmark_transcription.py` — ручные замеры с настоящей локальной моделью.

## Быстрые проверки

```powershell
.\.venv\Scripts\python.exe -B -m unittest test_transcription_service test_desktop test_text_formatting
```

Эти тесты не скачивают Whisper и не запускают реальную транскрибацию на GPU.

## Файлы вне Git

`.gitignore` исключает `.venv`, веса, исходные аудио/видео, логи и локальные настройки.
Готовые транскрипции сохраняйте в `transcripts/` или `outputs/`, чтобы они также не попали в Git.

## Portable-сборка

В `dist/LocalTranscriber-portable` находится автономная сборка для Windows x64.
Переносите всю папку, запускайте `LocalTranscriber.exe`; Python на целевом ПК не требуется.
Инструкция — [PORTABLE.md](PORTABLE.md). Ollama и SLM поставляются отдельно.

Для воспроизведения сборки из подготовленной `.venv` и скачанных русских весов:

```powershell
.\build_portable.ps1
```

Инструменты сборки устанавливаются только в `build/tools` с версиями из
`requirements-build.txt`; рабочие ML/GPU-пакеты не обновляются.
