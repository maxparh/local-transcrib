# Local Transcriber

Локальное Desktop-приложение для транскрибации аудио и видео на русском языке.
Интерфейс — PySide6 (Qt), распознавание — faster-whisper/CTranslate2.
Поддерживаются CPU и NVIDIA GPU; веб-интерфейса и HTTP-сервера нет.

## Запуск

Проверенное окружение: Windows, Python 3.11.9, локальная `.venv`.
Запустите `launch_desktop.bat` или выполните из папки проекта:

```powershell
.\.venv\Scripts\python.exe .\desktop.py
```

Выберите или перетащите файл, укажите CPU/GPU и нажмите «Транскрибировать».
Результат можно скопировать или сохранить в UTF-8.
Тип медиа определяется через PyAV, из видео извлекается аудиодорожка.
Созданные временные файлы удаляются после завершения обработки.

## Зависимости и модели

Точные версии рабочего окружения зафиксированы в `requirements.txt`.
Файл включает PyTorch `2.12.0+cu132`: для нового окружения требуется источник
соответствующих CUDA wheels; установка из одного стандартного PyPI не гарантируется.
Восстановление окружения на другом компьютере пока не проверено.
Не обновляйте GPU/ML-пакеты автоматически: используйте зафиксированные версии.

По умолчанию используется Whisper `large-v3`. При первом распознавании модель
загружается, затем используется локальный кэш. Модель не загружается при открытии окна.
Окружение и веса не входят в Git — на другом компьютере их потребуется подготовить отдельно.
Русская дообученная Whisper и опциональное SLM-форматирование пока не подключены.

## Конфигурация

Настройки находятся в `config.py` и переопределяются переменными `TRANSCRIBER_*`.
Например, выбор локальной модели и устройства на текущую сессию PowerShell:

```powershell
$env:TRANSCRIBER_MODEL_SOURCE = 'E:\Models\whisper-ct2'
$env:TRANSCRIBER_DEVICE = 'cuda'
.\.venv\Scripts\python.exe .\desktop.py
```

`MODEL_SOURCE` принимает идентификатор модели или путь к модели в формате CTranslate2.
Доступны также настройки языка, VAD, beam size, batch size и временной директории.

## Структура

- `desktop.py` — окно и точка входа.
- `desktop_worker.py` — операции вне GUI thread.
- `transcription_service.py` — модель и распознавание.
- `preprocessing.py` — определение медиа и подготовка аудио.
- `config.py` — настройки.
- `test_desktop.py`, `test_transcription_service.py` — быстрые проверки с mock-моделью.
- `benchmark_transcription.py` — ручные замеры с настоящей локальной моделью.

## Быстрые проверки

```powershell
.\.venv\Scripts\python.exe -B -m unittest test_transcription_service test_desktop
```

Эти тесты не скачивают Whisper и не запускают реальную транскрибацию на GPU.

## Файлы вне Git

`.gitignore` исключает `.venv`, веса, исходные аудио/видео, логи и локальные настройки.
Готовые транскрипции сохраняйте в `transcripts/` или `outputs/`, чтобы они также не попали в Git.
