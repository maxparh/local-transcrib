# Portable для Windows x64

Распакуйте весь архив в папку и запустите `LocalTranscriber.exe`.
Не переносите один EXE без соседних папок `_internal` и `models`.
Установка Python, FFmpeg и CUDA Toolkit не требуется.
Для GPU нужна совместимая NVIDIA-видеокарта и её драйвер; CPU доступен без NVIDIA.

Настройки и логи находятся в `data` рядом с EXE. Папка должна быть доступна для записи.
Исходные записи и результаты тестов в поставку не включены.
Русская Whisper находится в `models/whisper-russian`; интернет для неё не нужен.
Модель речи «исходная» требует отдельной установки весов и в эту поставку не включена.

Ollama и Qwen3 4B не входят в архив. Форматирование необязательно и выключено по умолчанию.
Чтобы его использовать, отдельно установите Ollama и `qwen3:4b-instruct`.
Без них распознавание аудио/видео продолжает работать.
При переносе на другой ПК Ollama и её модель автоматически не переносятся.

Сборка проверена локально на CPU и NVIDIA RTX 5070, с очищенными путями Python/CUDA,
в автономном режиме и после перемещения папки. Проверка на другом физическом ПК
пока не выполнена. Windows 10/11 x64 — целевая платформа этой сборки.

В `_internal` сохранены лицензии/метаданные включённых библиотек.
Источники модели и описание компонентов находятся в `components.json`.
